# 全國消防救護統計儀表板

互動式 Web 儀表板，呈現 113、114 年全國消防救護統計資料，涵蓋 22 個縣市，共 7 個分析頁籤、42 個圖表。

## 線上瀏覽

👉 **<https://你的帳號.github.io/ems-dashboard/>**（部署後請更新此連結）

## 功能

- **總覽**：核心 KPI、反應時間達成率、性別年齡分布
- **救護服務**：出勤分類、救護車數、未運送統計、創傷分布
- **OHCA 統計**：發生數、ROSC 率、旁觀者 CPR、PAD、事故地點
- **急救處置**：5 大類別與細項分析
- **時間年齡統計**：反應時間、平均各項時間、65 歲以上占比
- **人力資源**：消防/救護人力、EMT 等級、EMTP 服務人口數
- **不當使用收費**：KPI、原因分類、告知單與繳款率

## 篩選器

- 年份多選（113、114）
- 縣市多選（全選 / 清除 / 僅直轄市快捷鍵）
- 一鍵轉存 PDF（A4 橫向、自動加上篩選資訊與頁碼）

## 資料來源

內政部消防署一站通資料庫
